| 文档版本 | V1.0 (极简交付版) | 编制日期 | 2026-08-21 |
| :--- | :--- | :--- | :--- |
| 项目类型 | 微信小程序/Web应用 + 极简后台 | 核心理念 | 极简操作、零审批流、100%前后端真实交互 |
| 目标用户 | 超级管理员、分校管理员、专业教师、班委/家委、学员及家长 | 部署目标 | Vue 3 + Spring Boot + MyBatis XML + MySQL |

## 1. 项目定位与设计原则

### 1.1 核心设计原则
1. **零审批流原则 (Zero-Approval Flow)**
   - 彻底去除所有审核/审批环节。请假直接扣减并核销退回学位，补课预约立即生效；志愿者任务认领即扣减名额；采购记录录入即公示。
2. **数据真实性原则 (100% Real End-to-End Persistence)**
   - 拒绝前端假数据硬编码。所有功能均通过 Vue 3 Axios 请求调用 Spring Boot 接口，经 MyBatis XML 操作 MySQL 数据库读写。
3. **SSM经典架构与极致日志 (SSM Architecture & Deep Logging)**
   - 后端遵循 `Controller` -> `Service` -> `DAO (Mapper Interface)` 经典三层架构。
   - SQL 必须定义在 MyBatis XML Mapper 中，严禁使用 SQL 动态拼接字符串。
   - 接口入参、执行SQL前、业务处理点、异常及返回值全流程注入 SLF4J / Logback 详细日志。
4. **数据库初始全量种籽数据 (SQL Seed Data)**
   - 基础机构、舞种、用户角色、排课、量体、志愿者任务、结对子关系及问答知识库全部由初始化 SQL 脚本一键装载。

## 2. 角色与权限模型 (RBAC)

系统定义 5 种角色，通过 Token / Header 识别身份：

| 角色编码 | 角色名称 | 核心可用权限 |
| :--- | :--- | :--- |
| `SUPER_ADMIN` | 超级管理员 | 机构/校区管理、权限配置、全盘数据看板、全量数据重置与查询 |
| `ADMIN` | 教务管理员 | 排课创建与维护、师资管理、活动发布、公共采购记录发布 |
| `TEACHER` | 专业教师 | 本班课表管理（含着装规范）、考勤消课、学员量体录入、评语与成绩录入、私信回复与精选问答发布 |
| `COMMITTEE` | 班委/家委 | 志愿分工组长协同、家委排班值日、采购协助 |
| `STUDENT` | 学员/家长 | 查看个人课表与着装指南、一键请假与补课预约、量体档案查看与更新、认领志愿任务、结对子打卡、向老师1对1私信提问 |

## 3. 功能模块详细设计

### 3.1 教学教务与智能着装课表模块
- **课程排期发布**：包含舞种（中国舞/芭蕾/拉丁等）、教室、开课时间、任课老师及**《上课着装与装备规范》**（上身、下身、鞋履、发型要求、携带教具）。
- **今日课表与装备卡片**：学员端根据身份直接拉取今日/本周课表，醒目展示装备提示。
- **极简请假与补课 (无审批)**：
  - 学员点击“申请请假”，系统直接将该课时状态置为“已请假”，返还补课额度，无需老师/教务审批。
  - 学员选择有空余学位的补课场次点击“预约补课”，直接扣减补课额度并生成补课记录，无审批阻碍。
- **考勤消课**：老师选择对应课程点击“一键签到消课”，系统自动更新学员剩余课时数。

### 3.2 测评体系与动态量体档案模块
- **身材量体档案**：
  - 录入与查看学员 10 项身体维度指标：身高(cm)、体重(kg)、胸围(cm)、腰围(cm)、臀围(cm)、胴长(cm)、大腿围(cm)、臂长(cm)、鞋码(欧码/脚长cm)。
  - 记录量体时间轴，支持一键导出标准服装定制 Excel/JSON 数据。
- **成绩与评语记录**：老师直接录入基本功分值、剧目表现力、星级评定及文字点评，学员可实时查看成长曲线。

### 3.3 团队职责分工 (家委志愿协同) 模块
- **志愿者任务发布与认领 (无审批)**：
  - 组别：服装组、化妆造型组、餐饮后勤组、摄影摄像组、安保医疗组、交通联络组。
  - 管理员/老师发布任务并设定上限名额，家长点击“认领任务”即刻报名成功，名额自动 -1。
  - 组长或老师点击“核销签到”，增加家长的爱心志愿积分。

### 3.4 传帮带“结对子”互助模块
- **结对绑定与任务打卡**：
  - 老师匹配高年级学员与低年级学员建立“结对子”关系。
  - 结对双方在线提交练习打卡（如“指导盘头”、“共同压腿”），直接累积“姐妹星/兄弟星”勋章。

### 3.5 师生1对1私信与精选知识库模块
- **单向严格私信 (无学员间私信)**：
  - 学员只能向“本班任课老师”发起提问，选择问题分类（动作疑问/请假沟通/肌肉酸痛）。
  - 老师端实时查看并直接回复。
- **一键精选公开 (沉淀知识库)**：
  - 老师对优质问答点击“设为精选”，输入精选标题，系统自动脱敏学员姓名后发布至全局“舞蹈知识百宝箱”。

### 3.6 集中采购公示与家长会议排班模块
- **采购账目明细公示**：发布团购舞鞋、演出服、道具等费用明细与凭证，家长实时在线查验。
- **家长动员会与打扫排班 (无审批)**：发布线下/线上会议通知及排练厅打扫日历，家长一键认领值日日期。

## 4. 质量与交付标准

1. **接口全覆盖单元测试**：针对每一条 Controller 接口，编写 Spring Boot @SpringBootTest / MockMvc 测试用例，确保 Http 响应码为 200 OK 且返回正确 JSON。
2. **前端交互与状态测试**：前端基于 Vite + Vue 3 Component Testing / Vitest 测试组件渲染与 Pinia 状态交互。
3. **日志规范**：Controller 层打印请求 URI 及 JSON 负载；Service 层打印业务逻辑与影响行数；DAO 层由 MyBatis 打印具体 SQL 和绑定参数。
