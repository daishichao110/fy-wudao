## 1. 行业背景与竞品分析

### 1.1 行业现状与运营痛点
舞蹈培训机构（芭蕾、中国舞、拉丁舞、现代舞、K-pop等）在日常教务与演出协同中具有独特的业务壁垒：
1. **排课与装备通知高频严苛**：不同舞种对练功服（连体服/练功T恤）、练功袜（大袜/九分袜）、舞鞋（软底鞋/足尖鞋/高跟鞋）及发型（盘头丸子头/编发）有标准化要求，常规微信群通报易漏看，导致学员装备不合规影响教学。
2. **演出与考级协同复杂度极高**：演出服量体裁衣、化妆造型、后勤餐饮、道具管理等需多位家长志愿者紧密分工。传统打卡及沟通缺乏数字化工具。
3. **极简高效痛点**：传统教培 SaaS 系统往往设计了极其繁琐的请假审批、消课审批、采购审批等多级审批流，极大增加了老师和校长的日常人工负担。**机构迫切需要“无审批流、极简直接核销/生效”的高效体验。**

### 1.2 对标产品功能矩阵对比

| 功能维度 | 传统通用教培 SaaS | 微信群 / 拍立享等单点工具 | 本项目 (极简舞蹈学校小程序) |
| :--- | :--- | :--- | :--- |
| **排课与着装** | 仅支持基础排课时间地点 | 文字通告，易刷屏 | **课程排期 + 智能着装/装备卡片与提醒** |
| **流程审核机制** | 繁琐的多级审批流（需手动逐项审批） | 无系统，人工混乱 | **零审批流（极简即时生效，自动归档）** |
| **学员身材档案** | 无量体数据保存 | Excel/纸质记录，易丢失 | **动态量体档案库（历史轴 + 服装表一键导出）** |
| **家委志愿协同** | 无此功能 | 临时接龙，职责不清 | **志愿者职能分组（服装/化妆/后勤）与任务认领** |
| **高低年级传帮带** | 无此功能 | 线下口头交流 | **“结对子”互助积分与领航任务打卡** |
| **家校互动与私信** | 开放群聊或自由私信（易产生无序攀比） | 微信群私聊杂乱 | **严格1对1师生问答 + 优质问答一键精选公开** |
| **技术架构与测试** | 假数据演示 / 单体粗糙结构 | 静态网页原型 | **Spring Boot (SSM/XML Mapper) + Vue 3 + 100% 真实 SQL 数据与接口测试** |

## 2. 产品差异化核心策略

1. **极简无审批流架构 (Zero-Approval Flow)**
   - 彻底摒弃审批链。学员请假一键自动冻结/释放学位，补课预约一键即时核销，志愿任务一键认领打卡，提升教务处理效率 80% 以上。
2. **舞蹈专业化深度定制**
   - 包含上身、下身、鞋履、发型、教具 5 维度的上课装备卡片；保存身高、胸围、腰围、胴长、鞋码 10 项动态量体指标。
3. **沉淀家校知识资产**
   - 老师回复的高质量专业动作指导（如“芭蕾擦地如何规避扣脚”）可勾选为“精选公开”，脱敏后自动沉淀为校本舞蹈知识库。
4. **代码级真实交付标准**
   - 全端 Vue 3 + Spring Boot + MyBatis XML Mapper + MySQL 真实持久化，所有 API 均具备自动化测试与前后端连通性保障。

## 3. 研究结论与后续阶段规划

本次研究确立了**“专业舞蹈教务 + 家委志愿协同 + 极简零审批 + 真实前后端交互”**的产品建设方向。
